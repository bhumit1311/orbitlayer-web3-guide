Concept reference

Web3 fundamentals in comparison cards.

Simple side-by-side explanations for the ideas every new blockchain builder needs before writing smart contracts.

Web2 vs Web3

Web2

Apps are controlled by companies. Users log in with accounts, and data is stored on private servers.

Web3

Apps can use wallets, smart contracts, and public networks so users can own assets and verify activity.

Ethereum vs Bitcoin

Bitcoin

Designed mainly as decentralized money with a simple, secure transaction system.

Ethereum

Designed as programmable blockchain infrastructure where developers deploy smart contracts and apps.

Public Key vs Private Key

Public key

Used to receive funds and identify an address. It is safe to share publicly.

Private key

Used to sign transactions and prove ownership. Whoever has it controls the wallet.

Blockchain vs Traditional Database

Traditional database

Usually managed by one organization. Records can be edited by administrators with permission.

Blockchain

Shared across many nodes. New records are linked by hashes, making old data hard to change secretly.
